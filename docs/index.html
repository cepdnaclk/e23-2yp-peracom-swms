01 — Introduction

The Problem & Our Solution

Manual scholarship management is fragmented, opaque, and inefficient. PSWMS replaces it with a transparent digital ecosystem.

🔴 The Real-World Problem

University scholarship administration has historically relied on paper-based workflows and disconnected spreadsheets, creating significant challenges:

  • 📋Manual, error-prone application tracking across hundreds of students
  • ⏳Slow, opaque approval processes — applicants wait weeks without status updates
  • 🔒Donors have no visibility into how their funds are allocated or utilized
  • 📁Physical document management leads to lost files and compliance risks
  • 🔄No systematic workflow for donor-student matching and fund disbursement

🟢 Our Solution — PSWMS

A centralized, web-based platform that automates the entire scholarship lifecycle — from discovery to disbursement — through a role-based, transparent portal accessible to all stakeholders.

Automated Workflows Real-time Status Donor Transparency Secure Document Storage Multi-role Dashboard Progress Tracking

⭐ Impact & Value

PSWMS transforms scholarship management for all three stakeholder groups:

  • 🎓
    Students — Browse scholarships, apply via a guided 4-step wizard, track status in real-time, and submit semester progress reports from a single dashboard.
  • 💼
    Donors — Submit scholarship proposals, review assigned student dossiers, approve or reject individual applications, and verify payment disbursements with full audit trails.
  • ⚙️
    Administrators — Manage the full lifecycle: scholarship CRUD, application review, student-to-donor assignment, announcement publishing, issue resolution, and user account management.
  • 🏛️
    Institution — Improved compliance, reduced administrative overhead, and data-driven decision-making through consolidated statistics and activity feeds.

03 — Software Designs

Detailed Software Design

Nine interconnected database tables, three layered portals, and a comprehensive REST API spanning 40+ endpoints.

🎓

Student Module

  • Browse active scholarships (public + authenticated)
  • 4-step guided application wizard
  • Multi-file document upload via Supabase Storage
  • Real-time application status tracking
  • Semester progress report submission
  • Issue (support ticket) creation
  • Profile management & editing
💼

Donor Module

  • Submit scholarship proposals for admin review
  • Review assigned student dossiers
  • Approve / reject individual student applications
  • View semester progress reports
  • Payment disbursement verification
  • Targeted announcement viewing
  • Issue / support ticket system
⚙️

Admin Module

  • Live dashboard with stats + activity feed
  • Full scholarship CRUD & donor request review
  • Application review: approve / reject / resubmit
  • Student-to-donor assignment workflow
  • User approval queue + account lifecycle
  • Announcement: draft → publish → schedule
  • Issue tracking with threaded replies
🗃️

Database Design

  • users — all roles (admin / student / donor)
  • scholarships — active, inactive, draft
  • applications — multi-status lifecycle
  • application_documents — file references
  • donor_students — assignment records
  • progress_reports — semester reports
  • announcements, issues — communications
🔒

Security Design

  • JWT-based stateless authentication
  • bcryptjs password hashing (salted)
  • Role-based route guards (middleware)
  • Admin approval queue for new accounts
  • Supabase Row-Level Security policies
  • CORS configured for frontend domain
  • Environment variable secret management
🔄

Application Lifecycle

  • Pending — submitted by student
  • Under Review — admin reviewing docs
  • Approved — cleared by admin
  • Rejected — declined with reason
  • Resubmit — returned for corrections
  • Donor Assigned — matched to sponsor
  • Fully Approved — donor confirmed
